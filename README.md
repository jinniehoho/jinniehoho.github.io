# Jingyeong Hong — Data Analysis Portfolio

[Website](https://jinniehoho.github.io/) · [Steam analysis files](projects/steam-market-analysis/) · [English report](reports/steam-report.pdf)

This repository contains the static portfolio and a public snapshot of the Steam project. GitHub Pages publishes the website; notebooks are read on GitHub.

The Steam report contains exploratory findings, not sales/revenue forecasts. Notebook outputs and local metadata were removed. The complete raw → PostgreSQL → Power BI pipeline has not been reproduced for this release. SQL definitions are pending.

Raw and processed datasets, practice/exam files, virtual environments and PBIX files are excluded. Obtain data separately from the original publisher and check its license before reuse. The original local project is unchanged.
